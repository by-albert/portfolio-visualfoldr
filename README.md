# 📸 VISUALFOLDR

### Fotografía · Contenido · Desarrollo Web

**VisualFoldr** representa mi proyecto creativo y marca personal. Orientada a la creación de contenido visual, principalmente fotografía de **conciertos, deporte, moda y proyectos creativos que iré trayendo**.

Este proyecto nace con la intención de reunir mi trabajo fotográfico en un espacio propio, mostrar mi evolución y facilitar el contacto con artistas, marcas, eventos, deportistas y otros proyectos con los que colaborar.

🌐 **Portfolio:** https://portfolio-visualfoldr.vercel.app/

# 📷 Fotografía

Actualmente mi trabajo fotográfico se centra principalmente en cuatro áreas:

### ⚽ Deporte

Especialmente interesado en fotografía deportiva y, actualmente, en **fútbol sala**.

La fotografía deportiva requiere anticipación, rapidez y capacidad para reaccionar ante situaciones que duran apenas unos segundos.

En mis reportajes trabajo especialmente:

* Posicionamiento
* Elección de ángulos
* Anticipación de jugadas
* Timing
* Seguimiento de los protagonistas
* Configuración de cámara
* Selección de momentos clave

Uno de los proyectos realizados fue la cobertura de un **partido solidario de fútbol sala con 15 equipos**, donde tuve que cubrir el evento como único fotógrafo.

# ⚙️ Instalación

Si quieres ejecutar el proyecto localmente:

### 1. Clonar el repositorio

```bash
git clone [URL_DEL_REPOSITORIO]
```

### 2. Entrar en la carpeta

```bash
cd portfolio-visualfoldr
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar el servidor de desarrollo

```bash
npm run dev
```

El proyecto estará disponible en la dirección local indicada por Vite y React.

# 🧠 Filosofía

Una fotografía no debería limitarse a verse bien, debería transmitir algo.

Por eso, VisualFoldr busca trabajar cada proyecto desde una perspectiva visual, prestando atención a:

**Composición → Momento → Luz → Edición → Presentación**

El objetivo final es crear imágenes que tengan una razón para existir y que ayuden a cada proyecto a comunicar su propia identidad.
